🚨 Smart Gas Leakage Detector

📌 Project Overview

The Smart Gas Leakage Detector is an Arduino-based safety system designed to detect the presence of harmful gases and provide immediate alerts. The system uses a gas sensor to monitor gas levels continuously and activates visual and audio warnings when gas leakage is detected.

This project helps improve safety in homes, kitchens, laboratories, and industrial environments by providing early detection of gas leaks.

---

🎯 Objectives

- Detect gas leakage in real time.
- Provide immediate warning through LEDs and a buzzer.
- Improve safety and prevent accidents.
- Demonstrate sensor interfacing with Arduino.

---

🛠 Components Used

- Arduino UNO
- Gas Sensor (MQ-Type Sensor in Tinkercad)
- Red LED
- Green LED
- Piezo Buzzer
- 220Ω Resistors
- Breadboard
- Jumper Wires

---

⚙️ Working Principle

Safe Condition

- Green LED turns ON.
- Red LED remains OFF.
- Buzzer remains OFF.
- Area is considered safe.

Gas Leakage Detected

- Red LED turns ON.
- Green LED turns OFF.
- Buzzer turns ON.
- Warning alert is generated.

---

🔌 Connections

Gas Sensor

- VCC → 5V
- GND → GND
- Analog Output → A0

LEDs

- Green LED → D2
- Red LED → D3

Buzzer

- Positive Terminal → D4
- Negative Terminal → GND
